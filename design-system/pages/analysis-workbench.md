# Analysis workbench page

- Keep model discovery on the left and parameter configuration on the right for desktop widths.
- Search and category filters are above the list; selected model is highlighted with both a surface and a left rule.
- Configuration header shows module category, model name, and a one-sentence description.
- Show solver scope/assumptions in a warning/readiness note before users execute the model.
- Treat JSON as a technical editor: neutral surface, Fira Code, clear reset action and syntax guidance.
- Dataset binding is a separate step and shows the exact parameter-to-column mapping.
- Keep the primary `Run analysis` action visually clear; `Add to batch` remains secondary.
- On tablet/mobile, stack model browser above the selected model configuration.
