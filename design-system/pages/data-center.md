# Data center page

- The import panel and saved dataset list form a practical two-column workspace on desktop.
- The upload surface must explain accepted formats and the file-size limit before a user selects a file.
- Display selected filename, worksheet, preview dimensions, and validation warnings as text.
- Data preview is a real table with sticky or visible headings and horizontal scrolling—not a screenshot.
- Errors must be announced and appear beside the import action. Successful import must report row and column counts.
- Do not place decorative cloud imagery: imports are local and the file remains on the user's device.
