# Analysis results

- Treat a result as a technical report: model/status heading, key outputs, chart(s), tables, assumptions, and complete JSON details.
- Lead with the most meaningful mathematical outputs (for example objective value, total cost, MAD/MSE, project duration).
- Use a chart only when the output contains meaningful sequential or comparable numeric data.
- Keep axis/context notes and a legend; preserve series distinction with line style/markers as well as color when relevant.
- Show assumptions and limitations before the raw JSON block.
- Export actions (Excel, CSV, PDF) belong in the footer and should appear only for saved analyses.
