## Cara Memberikan Skill Ini ke ChatGPT

### Opsi A — ChatGPT Projects / Custom GPT Knowledge (Direkomendasikan)
1. Buat **Project** baru di ChatGPT (atau **Custom GPT**).
2. Upload `00_ALL_SKILLS_INDEX.md` ditambah 10 file di folder `bundles/` (total 11 file, aman di bawah batas 20 file Knowledge ChatGPT).
3. Tempel prompt instruksi dari `README_CHATGPT.md` ke bagian **Instructions** Project/GPT tersebut.

### Opsi B — Upload ZIP Langsung ke Chat ChatGPT
1. Upload `antigravity-all-skills.zip` (berisi seluruh folder skill termasuk `references/`, `scripts/`, `examples/`, dan `SKILL.md`).
2. Minta ChatGPT mengekstrak dan membaca `SKILL.md` yang relevan sesuai tugas Anda.
